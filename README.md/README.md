Meridian Run is an original 2D flight game: take the Swift off Meridian Field, thread three glowing rings over a dawn valley, and put her down on the far strip before the tanks run dry. It plays offline in a desktop browser from its own files — keyboard and mouse, with a lit HUD, fuel and stall discipline, and landings that read as what happened.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Fly with ↑↓ pitch, ←→ turn, W/S throttle, SPACE boost, P pause — or hold the mouse to steer toward the pointer.
